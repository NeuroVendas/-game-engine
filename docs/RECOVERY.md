## Product identity

Forge =] is AI-first, creator-first, a 3D engine + social game platform, deliberately approachable and influenced by classic creation culture without cloning another product.

## Canonical data

Humans, code and AI edit the same project representation.

Schema: `src/types.ts`

Format: `forge.scene v1`

## Editor/runtime rule

Play is temporary simulation. Stop restores authoring state unless a creator explicitly saves/applies a source change.

## Project Helios

Helios is the benchmark game used to pressure-test doors, clearance, power, scripts, UI, audio, alarms, multiplayer later and publishing.

## Known historical failure patterns

Do not reintroduce:

- compile-only confidence
- oversized root Babylon imports when granular imports work
- static-host absolute-path assumptions
- manipulation gimmicks worse than conventional 3D controls
- hidden runtime errors
- mandatory renderer effects that can crash boot
- fake social data before backend support
- private cloud cache leakage after sign-out

## Documentation policy

After meaningful subsystem changes:

1. update `CURRENT_STATE.md`
2. update `PROJECT_HISTORY.md` for milestones
3. append `DECISIONS.md` when assumptions change
4. update `ARCHITECTURE.md` when boundaries change
5. update tests in the same work

Documentation is part of implementation.
