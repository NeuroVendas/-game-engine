# Forge =] v0.5.0 — Release notes

**Release date:** 2026-10-09  
**Type:** First public v0.5 milestone (web engine and creator platform)  
**Repository:** https://github.com/NeuroVendas/-game-engine

Forge =] v0.5 introduces a creator-focused, in-browser 3D Studio and game runtime. The editor, scripting, platform pages and sample game now work together through the same `forge.scene` v1 format.

## What's included

- **Studio:** 3D scene hierarchy, groups, object placement, Move/Rotate/Resize, snapping, Undo/Redo, inspector and toolbar editing, hierarchy clipboard, rename and reusable project prefabs.
- **Assets and environment:** imported GLB models with embedded animation clips, imported images/audio, materials, sky, shadows, lights, collider debug and editable collider box proxies.
- **Gameplay:** Forge Classic character, WASD movement/jump/sprint, first/third-person camera, collision authoring, trigger volumes, hazards, checkpoints, player health, death and respawn.
- **Scripts and effects:** Script/LocalScript/ModuleScript, Forge scripting APIs, sound/UI, interactive world objects, particle/VFX presets.
- **Platform:** local projects, account/profile/cloud project features, Games/Favorites/Friends/Develop pages, catalog and direct play.
- **Playable sample:** **Core Relay**, with three interactive relays, UI, audio and a complete win/VFX sequence. Project Helios remains the ambitious, longer-term benchmark.

## Install / run

This is a **browser-first v0.5 release**, not yet a Windows installer. To run from source:

```bash
git clone https://github.com/NeuroVendas/-game-engine.git
cd -- -game-engine
npm install
npm run dev
```

To produce a static web build: `npm run check && npm run build`. Deploy the `dist` output to a static HTTPS host that supports Babylon.js/WebGL and serves relative assets.

**Website publication status:** GitHub Pages requires enabling Pages in repository Settings, choosing GitHub Actions as the source, then allowing the `Publish Forge v0.5 Website` workflow to deploy. A GitHub Release and a generated preview branch do not alone establish a reachable production website.

## What's next (not part of v0.5)
